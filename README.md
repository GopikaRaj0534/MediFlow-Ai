# MediFlow AI

MediFlow AI is a web-based hospital management system designed to simplify hospital operations and improve patient care through digital management and AI-powered features.

## Features

- **User Authentication:** Secure login for different user roles.
- **Admin Dashboard:** Manage hospital activities and users.
- **Doctor Dashboard:** Manage appointments and patient consultations.
- **Receptionist Dashboard:** Handle patient registration and hospital operations.
- **Patient Dashboard:** View appointments and personal information.
- **AI-Powered Features:** Machine learning-based symptom analysis.

## Technologies Used

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL
- **Machine Learning:** Python, Scikit-learn, Pandas, NumPy

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/GopikaRaj0534/MediFlow-Ai.git
   ```

2. Open the project folder:

   ```bash
   cd MediFlow-Ai
   ```

3. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure your database and environment variables.

5. Run the application:

   ```bash
   python app.py
   ```
